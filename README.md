# Financial Analysis Tool

A Python-based financial analysis tool that retrieves company financial data and automatically calculates key financial metrics.

## Current Features

- Retrieve company financial data using a stock ticker
- Analyze income statement data
- Analyze balance sheet data
- Calculate revenue growth
- Calculate net profit margin
- Calculate return on assets (ROA)
- Calculate return on equity (ROE)
- Calculate current ratio
- Calculate debt-to-equity
- Generate an Excel financial report

## Technologies

- Python
- Pandas
- yfinance
- openpyxl
- Microsoft Excel
